# 🌿 NGO Volunteer Portal

## 📌 Description
A web platform that connects NGOs with volunteers for events and activities.

## 🚀 Features
- User & Admin Login
- Event Management (Add, Delete, Join)
- Multilingual Support (English, Hindi, Kannada)
- Feedback with rating
- Certificate Upload & Download
- Notifications System

## 🛠 Technologies Used
- PHP
- MySQL
- HTML, CSS
- Bootstrap
- JavaScript
